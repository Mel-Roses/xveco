# Contribuir al proyecto

¡Todas las contribuciones son bienvenidas y agradecidas! 

## ¿Cómo puedo colaborar?

1. **Reportar un Bug**: Si encuentras un error, abre un [Issue](../../issues) describiendo los pasos para reproducirlo.
2. **Proponer Mejoras**: Si tienes una idea, abre un Issue para discutirla antes de ponerte a programar.
3. **Enviar Código (Pull Requests)**:
   - Haz un **Fork** del repositorio.
   - Clona tu fork en tu máquina local (`git clone <url>`).
   - Crea una rama para tu nueva característica (`git checkout -b feature/nueva-caracteristica`).
   - Haz tus cambios y súbelos (`git push origin feature/nueva-caracteristica`).
   - Abre un **Pull Request** hacia la rama `main` (o `master`) de este repositorio.
